# 아침 단어 알리미

GitHub Pages로 배포할 수 있는 정적 웹사이트입니다.

## 포함 파일
- `index.html`: 홈페이지 전체 코드(HTML, CSS, JavaScript)
- `README.md`: 실행 및 배포 안내

## GitHub Pages 배포
1. GitHub에서 새 저장소를 만듭니다(예: `morning-word-alert`).
2. `index.html`과 `README.md`를 저장소 최상위(root)에 업로드합니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. **Build and deployment**에서 `Deploy from a branch`를 선택합니다.
5. Branch는 `main`, 폴더는 `/(root)`로 선택하고 저장합니다.
6. 잠시 기다린 뒤 Pages 화면의 `Visit site`를 누릅니다.

## 사용 방법
홈페이지에서 **단어집 관리**를 눌러 `영단어, 뜻` 형식으로 입력한 뒤 **저장하고 적용**을 누릅니다.

예:
apple, 사과
book, 책
school, 학교

## 동작 규칙
- 평일 오전 7시부터 하루 최대 5개 단어를 표시합니다.
- 평일 오전 7시 전에는 직전 평일 단어를 표시합니다.
- 토요일과 일요일에는 단어를 표시하지 않고 휴식 안내를 보여줍니다.
- 첫 학습일부터 월~금만 학습일로 계산하며, 단어집 끝에서는 처음부터 반복합니다.
- 단어집과 날짜 설정은 해당 브라우저의 로컬 저장소에 저장됩니다.
- 날씨 표시에는 인터넷 연결과 위치 권한이 필요합니다.

## 테스트
1. 단어 10개 이상을 넣고 저장한 뒤 새로고침해 저장 여부를 확인합니다.
2. 12개 단어로 첫 학습일 1~5번, 다음 평일 6~10번, 그다음 평일 11~12번과 1~3번이 표시되는지 확인합니다.
3. 토요일이나 일요일에는 단어 대신 주말 안내가 표시되는지 확인합니다.
4. 목표 날짜를 오늘/내일/과거로 바꿔 D-Day 표기를 확인합니다.
5. 위치 권한을 허용해 날씨가 표시되는지 확인합니다.
6. PC와 휴대폰 화면에서 레이아웃을 확인합니다.

## 참고
단어집은 브라우저와 기기별로 저장되며 다른 사용자와 자동 동기화되지 않습니다. 여러 사람이 단어집을 공유하려면 별도 데이터베이스나 백엔드가 필요합니다.
